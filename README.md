# Fire Extinguisher Detection

Исследовательский проект по сравнению централизованного, локального и федеративного обучения моделей компьютерного зрения для обнаружения огнетушителей на синтетических изображениях офисных помещений.

**Технологии:** Python, PyTorch, YOLO11, Ultralytics, CUDA.

Подробное описание методологии, экспериментов и результатов: [experimental_results.md](experimental_results.md).
